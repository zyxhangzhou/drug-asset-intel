# 术语对照表

本项目横跨生物医药与资本交易。下表按主题分组，每个术语给出英文、中文和通俗解释。项目内部自定义的词放在最后一节。

## 1. 交易与资本

| 术语 | 中文 | 通俗解释 |
|---|---|---|
| MNC (Multinational Corporation) | 跨国药企 | 本项目的 10 家"买方"，如辉瑞、默沙东、诺华。体量大、现金多，靠收购补充产品线。 |
| M&A (Mergers & Acquisitions) | 并购 | 买下整家公司。买方得到公司的全部资产，也承担它的全部负债和问题。 |
| Licensing / License deal | 授权许可 | 不买公司，只买某个药在某些地区的开发和销售权。通常先付一笔首付款，之后按里程碑和销售额分成。 |
| Upfront | 首付款 | 授权或收购签约时立刻支付的钱。 |
| Milestone | 里程碑付款 | 药物达到某个节点（如 3 期成功、获批上市）后才支付的钱。不保证一定能拿到。 |
| Royalty | 销售分成 | 药物上市后，按销售额的一定比例持续支付给原公司。 |
| Co-development / Co-commercialization | 共同开发 / 共同商业化 | 两家公司一起出钱开发或一起卖药，按约定分利润。资产因此不完全属于一家公司。 |
| Option / ROFR / ROFN | 选择权 / 优先购买权 / 优先谈判权 | 某家公司已提前锁定"以后优先买或优先谈"的权利。其他买方想买时会被卡住，是交易障碍。 |
| Market cap | 市值 | 股价 × 流通股数。市场认为这家公司的股权值多少钱。 |
| Shares outstanding | 流通股（已发行股数） | 公司在外面的全部股票数量。增发后会变多，市值计算要用最新的数。 |
| EV (Enterprise Value) | 企业价值 | 市值 + 债务 − 现金。粗略代表"买下整家公司实际要花多少"：现金归买方，债务也归买方。 |
| Premium | 收购溢价 | 收购价高出当前股价的部分。生物科技收购溢价常见 50%–100%。 |
| Cash runway | 资金可支撑时间 | 现有现金按当前烧钱速度还能撑几个月。短说明公司很快要融资或找合作。 |
| Burn rate | 烧钱速度 | 每月的经营现金净流出。 |
| Operating cash flow | 经营现金流 | 日常经营带来的现金进出。研发型公司通常是负数。 |
| Dilution | 稀释 | 公司增发新股融资，老股东的持股比例下降。 |
| Firepower | 收购能力（火力） | 买方可用于并购的资金规模（现金 + 可借的钱）。 |
| BD (Business Development) | 业务拓展 | 药企里负责找资产、谈授权和收购的部门。 |
| Ticker | 股票代码 | 如 VKTX（Viking）、MDGL（Madrigal）。 |
| S&P Biotech Index (XBI) | 标普生物科技指数 | 本项目 149 家标的公司的来源清单。 |

## 2. 专利与产品生命周期

| 术语 | 中文 | 通俗解释 |
|---|---|---|
| LOE (Loss of Exclusivity) | 独占期丧失 / 专利悬崖 | 药的专利或市场独占期到期，仿制药或生物类似药可以上市。原药收入通常会大幅下降，所以药企要提前买新药填补。 |
| Patent cliff | 专利悬崖 | 多个大品种在相近时间 LOE，收入像掉下悬崖。 |
| Generic | 仿制药 | 化学药专利到期后，其他公司生产的同成分药，价格便宜很多。 |
| Biosimilar | 生物类似药 | 生物药（如抗体）专利到期后的"仿制品"。 |
| Exclusivity | 市场独占期 | 法规给新药的一段保护期，期间仿制药不能获批，独立于专利。 |
| Franchise | 产品系列 / 业务板块 | 一家药企在某个疾病领域的一组产品，如默沙东的肿瘤业务。 |

## 3. 药物研发与临床试验

| 术语 | 中文 | 通俗解释 |
|---|---|---|
| Pipeline | 管线 | 一家公司在研发中的全部药物及其进度。 |
| Asset | 资产 | 一个在研或已上市的药物项目。买方交易的对象。 |
| Preclinical | 临床前 | 还在实验室和动物上做实验，没进入人体。 |
| Phase 1 | 1 期临床 | 第一次给人用，主要看安全性和剂量，人数少（几十人）。 |
| Phase 2 / 2b | 2 期 / 2b 期 | 在患者身上初步看疗效、找合适剂量。2b 一般更大、更严格，接近关键试验。 |
| Phase 3 | 3 期临床 | 大规模确认疗效和安全性（数百到数千人），通常是获批的主要依据。 |
| Pivotal trial | 关键性试验 | 用来支持上市申请的那项试验，通常是 3 期，有时是设计严谨的 2 期。 |
| Phase 4 | 4 期 / 上市后研究 | 药已获批后继续做的研究。 |
| Readout | 数据读出 | 试验结束后公布结果的时刻。股价常在此时大涨或大跌。 |
| Catalyst | 催化事件 | 会显著影响公司价值的未来事件，如关键数据读出、FDA 审批决定。 |
| Indication | 适应症 | 药物用来治疗的具体疾病，如"肥胖""非酒精性脂肪性肝炎"。 |
| Therapeutic area (TA) | 治疗领域 | 适应症的大类，如肿瘤、免疫、代谢、神经。 |
| MoA (Mechanism of Action) | 作用机制 | 药物在体内起作用的方式，如"抑制某个蛋白""激活某个受体"。 |
| Target | 靶点 | 药物作用的分子，如 GLP-1 受体、PD-1。注意：本项目里"标的"指被研究的公司，与靶点不同。 |
| Modality | 技术类型（药物形式） | 药物"是什么做的"：小分子、抗体、ADC、双抗、细胞疗法、基因疗法、RNA 药物等。 |
| Small molecule | 小分子药 | 化学合成的药，常可口服。 |
| Biologic / mAb | 生物药 / 单克隆抗体 | 用生物方法生产的大分子药，通常需要注射。 |
| ADC (Antibody-Drug Conjugate) | 抗体偶联药物 | 抗体连上毒性药物，把药精准送到肿瘤细胞。 |
| Bispecific | 双特异性抗体（双抗） | 一个抗体同时结合两个靶点。 |
| Cell / Gene therapy | 细胞 / 基因疗法 | 改造患者细胞或直接修改基因来治病，如 CAR-T。 |
| SoC (Standard of Care) | 标准治疗 | 目前医生对这种病的常规治疗方案。新药要比它好才有价值。 |
| Head-to-head | 头对头比较 | 在同一项试验里直接比较新药和现有药。证据最强。 |
| Cross-trial comparison | 跨试验比较 | 拿两项不同试验的结果相比。人群和终点定义可能不同，结论要打折扣。 |
| Randomized controlled trial (RCT) | 随机对照试验 | 患者随机分到新药组或对照组，可以排除很多偏差。证据强度高。 |
| Single-arm | 单臂试验 | 所有患者都用新药，没有对照组。常见于早期肿瘤试验，证据较弱。 |
| Placebo | 安慰剂 | 外观相同但不含药的"假药"，作对照用。 |
| Endpoint | 终点 | 试验用来判断有没有效的指标。 |
| Primary endpoint | 主要终点 | 试验事先指定的最重要指标。是否"达到主要终点"决定试验成败。 |
| Surrogate endpoint | 替代终点 | 不直接衡量患者获益、但与之相关的指标，如肿瘤缩小、化验值下降。比生存期等终点弱。 |
| ORR / PFS / OS | 客观缓解率 / 无进展生存期 / 总生存期 | 肿瘤试验常用终点：肿瘤缩小的比例 / 病情不恶化的时间 / 活多久。OS 最有说服力。 |
| p-value | p 值 | 结果由偶然造成的可能性。通常小于 0.05 算"统计学显著"。 |
| Enrollment | 入组 | 试验招募的患者人数。 |
| Primary completion date | 主要完成日期 | 最后一名患者完成主要终点评估的日期。数据读出通常在此之后几个月。 |
| Sponsor / Lead sponsor | 申办方 / 牵头申办方 | 发起并负责这项试验的机构。本项目按牵头申办方把试验归到公司。 |

## 4. 监管与审批

| 术语 | 中文 | 通俗解释 |
|---|---|---|
| FDA | 美国食品药品监督管理局 | 美国药品审批机构。 |
| EMA | 欧洲药品管理局 | 欧盟药品审批机构。 |
| IND | 新药临床试验申请 | 进入人体试验前向 FDA 提交的申请。 |
| NDA | 新药上市申请 | 化学药申请上市。 |
| BLA | 生物制品上市申请 | 生物药申请上市。 |
| PDUFA date | PDUFA 日期（审批目标日） | FDA 承诺给出审批决定的日期。是很重要的催化事件。 |
| Breakthrough Therapy | 突破性疗法认定 | FDA 给早期数据很好的药的加速资格，审批沟通更多更快。 |
| Accelerated approval | 加速批准 | 基于替代终点先批准上市，之后必须用确证性试验补证据。 |
| Orphan drug | 孤儿药 | 治疗罕见病的药，有额外的独占期和优惠。 |
| Drugs@FDA | FDA 药品数据库 | FDA 官网上查已批准药品的数据库。本项目用 openFDA 接口读取。 |

## 5. 数据来源

| 术语 | 中文 | 通俗解释 |
|---|---|---|
| ClinicalTrials.gov（CT.gov） | 美国临床试验登记网站 | 全球最大的临床试验登记库，试验状态、设计、入组、完成日期都在这里。 |
| SEC | 美国证券交易委员会 | 美国上市公司监管机构，公司必须向它提交财报。 |
| EDGAR | SEC 电子申报系统 | 查上市公司所有官方申报文件的网站。 |
| 10-K / 10-Q | 年报 / 季报 | 美国上市公司的官方年度和季度财务报告。 |
| 8-K | 重大事项报告 | 公司发生重大事件（如收购、关键数据）时提交的临时报告。附件 99.1 常是新闻稿。 |
| 20-F | 外国公司年报 | 外国公司在美国上市时提交的年报，常用 IFRS 会计准则。 |
| XBRL | 可扩展商业报告语言 | 财报里的数字带有机器可读的标签，程序可以直接取"现金""债务"等数值。 |
| CIK | SEC 公司编号 | SEC 给每家公司的唯一编号。 |
| openFDA | FDA 开放数据接口 | FDA 提供的程序接口，本项目用它取已获批产品。 |
| IR (Investor Relations) | 投资者关系 | 公司官网上给投资者看的栏目，有新闻稿、演示材料、电话会记录。 |

## 6. 本项目内部术语

| 术语 | 通俗解释 |
|---|---|
| 买方 | 对方材料里的 10 家跨国药企。 |
| 标的 | 标普生物科技指数里被研究的 149 家公司。 |
| 候选池 | 去掉 Stage 0 排除名单后剩下的 133 家。 |
| Stage 0 排除 | 先排除明显不适合的公司：已被收购、自己就是大药企、不做治疗药物。 |
| 推荐组合 | 一家公司的"主推荐资产 × 适应症 × 主要买方"。评分全部针对这一个组合。 |
| 保守分 / 乐观分 | 缺失信息按 0 分算 / 按满分算。保守分用来决定推荐，乐观分用来决定是否值得研究。 |
| 证据覆盖率 | 10 个必需字段中有来源支撑的比例。 |
| 研究状态 | 自动初筛 / 已复核 / 深度研究，表示研究做到了哪一步。 |
| 来源（Source）| 一个可点击的原始出处：网页、申报文件、试验登记页。每个来源有 ID，如 `SEC-…`、`CTG-NCT…`。 |
| 声明（Claim）| "某个数值来自某个来源"的一条记录。每个业务数值都至少有一条。 |
| 事实 / 推断 | 事实：来源原文直接写着。推断：我们根据来源做出的判断，必须附置信度。 |
| 置信度 | 推断的可靠程度：高 / 中高 / 中 / 低。 |
| 待核实 | 没找到来源的字段。留空并标出，不填估算值。 |
| 缺口清单 | `data/processed/gaps.csv`，列出所有缺失数据及原因。 |
| 快照日 | 2026-10-28。所有股价、财务数据都以这一天为准。 |
| 推导管线 | 程序从 CT.gov 试验的干预药物名推出来的管线，属于推断，可能有误。 |
| 交叉核对 | 两个不同的 LLM（DeepSeek 和 Qwen）各抽一遍，结果不一致的交给人工复核。 |
