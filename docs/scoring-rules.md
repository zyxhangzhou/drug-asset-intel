## 1. 列表的一行要回答的问题

| # | 问题 | 列表列 | 评分维度 |
|---|---|---|---|
| 1 | 这家公司有什么值得关注的资产？ | 核心资产及适应症 | —（决定评分对象） |
| 2 | 哪家药企可能需要它，为什么？ | 潜在买方及匹配理由 | 买方契合度、研发阶段匹配度 |
| 3 | 临床证据有多强？ | 临床证据与差异化 | 临床证据与差异化 |

## 2. 评分对象：推荐组合

- **推荐组合** = （公司，主推荐资产，适应症，主要买方）。五个维度全部针对同一个推荐组合打分。
- 每家公司只取一个主组合。**公司分 = 主组合的分数。** 其他资产、其他买方的组合列在详情页，不计入公司分。这样不会出现"契合度看资产 A、证据看资产 B"拼出的高分。
- **资产**：同一药物在 CT.gov 推导管线中合并后的一条（代号、通用名、商品名视为同一资产）。**适应症**：该资产研发阶段最高的适应症；复核时可以改选，必须写理由。
- **主组合的选择**：在候选组合中取保守分（第 4 节）最高的一个；同分时取证据覆盖率高的。复核时分析人员可以改选，必须写理由。

## 3. 五个维度的刻度

每个维度打 0–4 整数分。每一档都写明需要什么证据。达不到某一档的证据要求，就落到下一档。

### 3.1 买方契合度（30%）

买方需求的来源（全部来自对方材料，已入库）：

- `buyer_preference`：每家买方 3 个治疗领域 + 3 个技术类型偏好，含"目标资产画像"（`target_profile`）和需求类型。
- `buyer_product_loe`：买方主要产品的美国专利到期（LOE）时间。

| 分 | 要求 |
|---|---|
| 4 | 资产对应该买方的**一条具体需求**：对方材料"目标资产画像"中的具体描述（适应症、机制或给药方式），或填补该买方某个 LOE 产品所在领域。并且未发现该买方已有同机制、同适应症的资产。 |
| 3 | 资产落在该买方前三治疗领域内，技术类型也符合其技术偏好，但没有对应到一条具体需求。 |
| 2 | 只符合治疗领域，或只符合技术类型（标签匹配）。 |
| 1 | 相邻领域，匹配勉强。 |
| 0 | 不符合；或该买方已持有同机制、同适应症的资产（组合冲突）。 |

- 自动初筛最高给 2 分。3–4 分必须在复核时写出一句"需求条目 → 资产属性"的对应说明，两端各挂来源。

### 3.2 研发阶段匹配度（20%）

阶段顺序：临床前 < 1 期 < 2 期 < 3 期 < 注册申请 < 已上市。

| 分 | 要求 |
|---|---|
| 4 | 资产阶段落在该买方（对应偏好行）的理想阶段区间内。 |
| 2 | 与理想区间相差一个阶段。 |
| 0 | 相差两个阶段及以上。 |

- 不默认越晚越好。例：买方偏好"Phase 2-3"，已上市资产只得 2 分。
- 理想阶段取对方材料的 `ideal_stage`。它只在治疗领域偏好行中填写，技术类型行没有；因此以匹配到的治疗领域行为准。
- 资产阶段：初筛用 CT.gov 推导的最高登记阶段（推断，中）；复核时用公司最新披露确认。

### 3.3 临床证据与差异化（20%）

每个推荐组合都记录四项：**研究设计、可比性、结果、局限**。四项都写进详情页，分数按下表：

| 分 | 要求 |
|---|---|
| 4 | 随机对照的 2b / 3 期试验达到主要终点，效应有临床意义；并且与标准治疗有直接对比，或与标准治疗的关键试验在同终点、同人群下的间接比较显示优势。 |
| 3 | 随机 2 期达到主要终点；或单臂试验在单臂数据可作注册依据的领域（如部分肿瘤的缓解率）显示明显效应。 |
| 2 | 早期（1 期或单臂）阳性信号；或结果阳性但看不出相对标准治疗的优势。 |
| 1 | 没有公开的人体疗效数据（只有安全性、药代或临床前数据）。 |
| 0 | 主要终点失败，或出现导致暂停的安全性问题，且没有后续数据解释。 |

- 只有跨试验比较时，最高 3 分，并在"可比性"中写明"跨试验比较，人群与终点定义可能不同"。
- 替代终点（非注册终点）的结果最高 3 分。
- 自动初筛只用 CT.gov 已发布结果，最高 2 分。程序判断不了效应是否有临床意义。

### 3.4 近期催化（15%）

- **窗口**：快照日（2026-10-28）起 24 个月内。只算主推荐资产的事件。同一资产在其他适应症上的事件也可以计入，事件文本必须写明适应症（2026-10-30 用户确认）。
- **重要性**：
  - 高：关键性试验读出、监管决定（PDUFA 日期、EMA 意见）、上市申请提交。
  - 中：2 期读出、关键性试验启动。
  - 低：1 期数据、学术会议更新。
- **时间确定性**：
  - 明确披露：公司公告给出季度或更细的时间（事实）。
  - 登记估算：只有 CT.gov 的预计主要完成日期。日期本身是登记事实；"读出时间"是推断，列表中标「估算」。

| 重要性 \ 确定性 | 明确披露 | 登记估算 |
|---|---|---|
| 高 | 4 | 3 |
| 中 | 3 | 2 |
| 低 | 1 | 1 |

- 窗口内没有事件：0 分。

### 3.5 可交易性（15%）

三项分开展示。只有**成本**计分；**资产权益**是门槛；**资金情况**只做提示。

**成本（计分）**：企业价值 EV = 市值 + 债务 − 现金及投资。

| 分 | EV |
|---|---|
| 4 | < 20 亿美元 |
| 3 | 20–50 亿 |
| 2 | 50–150 亿 |
| 1 | 150–400 亿 |
| 0 | > 400 亿 |

- 用绝对档位，不按买方的收购能力计算：对方材料里 10 家买方中有 7 家的现金字段为空（第 9 节）。买方财务数据齐全时，详情页另外写出 EV 占买方现金的比例。
- 推荐交易形式是许可或合作时，EV 只作参考，详情页写明。

**资产权益（门槛）**：主推荐资产的全球权益是否在公司手里。

| 状态 | 处理 |
|---|---|
| 完整 | 无影响 |
| 部分（某些区域已授权给他人） | 可交易性最高 3 分；写明区域 |
| 受限（他方对**推荐交易所涉地区**持有选择权、优先谈判权，或共同开发 / 共同商业化 / 利润分成；只是其他地区已授权出去、或授权方分担其所在地区费用，判「部分」——2026-10-30 用户确认） | 全资收购方案不成立。推荐交易形式与限制兼容（如区域许可）时，可交易性最高 1 分；不兼容时不进入入选名单 |
| 待核实 | 不得进入入选名单。复核时必须读 10-K 中合作协议的段落 |

**资金情况（提示，不计分）**：

- 资金可支撑 < 12 个月：提示「融资压力」。含义：公司近期可能增发或寻求合作，估值和谈判条件可能变化。**不解释为"容易收购"。**
- 经营现金流为正：提示「自给」。
- 其余：显示可支撑月数。

## 4. 吸引力分、证据覆盖率与研究状态

三个量分开显示，不合成一个数。

**吸引力分**

- 保守分 = Σ 权重 × 维度分 / 4 × 100。缺失的维度按 0 分计。
- 乐观分 = 同一公式，缺失的维度按 4 分计。
- 列表显示保守分，旁边显示区间（保守分–乐观分）。区间越宽，说明研究越不充分。

**证据覆盖率** = 有来源支撑的必需字段数 ÷ 必需字段数。必需字段共 10 个：

1. 资产名称
2. 适应症
3. 研发阶段
4. 买方需求条目
5. 匹配说明
6. 研究设计
7. 主要结果
8. 下一事件及时间
9. EV 的三个输入（市值、现金、债务；三者都有才计为覆盖）
10. 资产权益状态

**研究状态**

| 状态 | 含义 |
|---|---|
| 自动初筛 | 只有程序从结构化数据算出的分数 |
| 已复核 | 人工（Claude 辅助）确认了推荐组合、必需字段与来源 |
| 深度研究 | 变更 F 的 3–5 家，临床数据、催化事件、收购成本全部人工核对 |

**缺失值**：没有来源的字段显示「待核实」，不填估算值。它在保守分里按 0 计，在乐观分里按 4 计。

## 5. 排序与入选流程

1. **初筛（133 家，自动）**：按**乐观分**排序，取前 40 家左右进入复核。乐观分决定"值得研究"，避免信息少的公司在研究前就被淘汰。
   - 人工加入：`config/scoring.toml` 的 `longlist_extra` 列出的公司也进入复核。用于主组合按保守分选中已上市产品、乐观分因此下降的公司（当前：IONS、VNDA）。已复核的公司始终留在复核池。
2. **复核（约 40 家）**：确定推荐组合，补齐必需字段，核对资产权益，写两句话论点（第 7 节）。
3. **入选名单（20–30 家）**：按**保守分**排序。入选条件：
   - 研究状态为「已复核」或「深度研究」；
   - 资产权益不是「待核实」，也不是与推荐交易形式不兼容的「受限」；
   - 两句话论点写得出来，且每个事实都有来源。
4. **深度对象（3–5 家）**：从入选名单前列中选，兼顾不同买方和不同领域。最终由用户确认。

保守分决定"值得推荐"：研究不足的公司缺失项按 0 计，不会因为风险还没被发现而排在前面。

## 6. 样例检验

首批复核完成约 10 家后，执行以下检验。结果记入本文和 `docs/ai-log.md`，再决定是否调整权重或细则。

1. **分数与证据一致**：每个 3–4 分的维度都有事实声明支撑。用程序检查。
2. **排序与判断一致**：分析人员在看分数前，先把这 10 家独立分为高、中、低三档，再与保守分排序对比。每个不一致都写原因，然后改细则或改分。
3. **权重敏感性**：每个权重分别 ±10 个百分点（其余按比例缩放），比较前 20 名的变化。超过 5 家变动时，讨论权重。
4. **覆盖偏差**：保守分前 10 名中，证据覆盖率低于 70% 的公司数必须为 0。

## 7. 两句话论点

每家入选公司必须能写出下面两句。每个尖括号对应一条来源；没有来源的位置写「待核实」。第一句写不出来的公司不入选。

> 第一句：〈买方〉需要〈需求条目〉；〈公司〉的〈资产〉（〈机制〉，〈适应症〉，〈阶段〉）对应这一需求，因为〈对应理由〉。
> 第二句：证据是〈关键数据及可比性〉；下一事件是〈事件〉（〈时间〉，〈明确披露 / 估算〉）；主要障碍是〈成本、权益或资金中最突出的一项〉。

## 8. 默认列表字段

| 列 | 内容 | 主要来源 |
|---|---|---|
| 公司 | ticker、名称、市值 | 指数清单、SEC、Nasdaq |
| 核心资产及适应症 | 资产名、机制、适应症、阶段 | CT.gov、FDA、公司披露 |
| 潜在买方及匹配理由 | 买方名 + 一句"需求 → 资产"对应 | 对方材料 + 资产来源 |
| 临床证据与差异化 | 一句结论 + 分数（设计、可比性、结果、局限在详情页） | CT.gov 结果、公司披露 |
| 下一关键事件 | 事件、时间、「明确披露」或「估算」标签 | 公司披露、CT.gov |
| 交易障碍 | EV 档位、权益状态、资金提示 | SEC、Nasdaq、10-K |
| 研究状态 | 状态 + 证据覆盖率 | 系统计算 |
| 吸引力分 | 保守分 + 区间；用于排序，不替代上面各列 | 系统计算 |

- 每个单元格都可以跳到它的声明与来源。
- 「待核实」显示为标签，不显示为空白。
- 详情页显示五个维度的分数与理由、其他组合、缺口清单。
- 权重写在配置文件中；修改后可以重新生成排名。

## 9. 未核验的假设

| 假设 | 状态 | 核验方法 |
|---|---|---|
| EV 档位的分界（20 / 50 / 150 / 400 亿美元）合理 | 未验证 | 样例检验第 2、3 项 |
| 初筛用条件文本关键词把试验映射到买方的治疗领域，准确度够用 | 未验证 | 复核时抽查映射结果，并记录错误率 |
| 复核每家约 10–15 分钟，40 家可在 1.5 天内完成 | 已验证（不同于假设） | AI 子代理起草每家 5–13 分钟，45 家并行约 1 小时；人工签字时间另计 |
| 资产权益可以从 10-K 合作协议段落判断 | 部分验证 | 45 家均据 10-K / 10-Q 判定；其中多家没有「全资」原句，按合作披露的完整列举推断（置信度中高或中） |
| 取前 40 家进入复核足以产出 20–30 家入选 | 已验证 | 45 家复核（含人工加入），按保守分取前 30 家 |

已确认的数据限制（来自快照库）：

- 对方材料的买方财务中，只有 Merck、BMS、Pfizer 填了现金；其余 7 家为空。因此成本按绝对 EV 档位计算。
- `ideal_stage` 只在每家买方的 3 个治疗领域偏好行中填写，技术类型行为空。

复核中确认的数据限制（2026-10-30，45 家复核后）：

- **买方集中**：Pfizer #2（靶向小分子，覆盖乳腺、泌尿）与 AstraZeneca #2（罕见病、基因疗法）各被 6 家选为买方。这反映对方材料中这两条偏好的覆盖面，不做人为限额（用户确认）。
- **CBER 审批的生物制品不在 Drugs@FDA**：溶瘤病毒、基因疗法、细胞疗法等由 CBER 审批，openFDA drugsfda 没有记录，快照不会把它们标为已上市（例：REPL 的 RP1）。复核时以公司披露为准。
- **说明书匹配可能偏宽**：试验适应症比说明书适应症宽时（如「Ovarian Cancer」对说明书「低级别浆液性卵巢癌」），仍会标为已上市。只影响自动初筛分；复核以人工判断为准。
- **新获批产品可能缺说明书**：openFDA 说明书接口没有收录的 6 个获批申请记入缺口清单，阶段未修正。
- **快照日后的融资不计入**：VSTM、RCUS、TYRA、ERAS 在 2026 年 9–10 月增发，快照按 2026-10-28 前申报的数据计算，EV 与资金月数未反映增发。
- **特许权出售负债**：公司自定义 XBRL 标签不在 companyfacts 接口中。已知的 PTCT、RGNX 两家通过 `data/manual/debt_adjustments.csv`（有来源、有签字）计入 EV；其他公司若有同类负债，可能漏计。
- **推导管线缺资产**：只来自 CT.gov 牵头申办的试验，未登记或由合作方申办的资产缺失（例：PTCT 的 ST-920、CABA 的肌炎适应症）。

## 10. LLM 抽取结果的入库规则

适用于 `intel extract` 从新闻稿、财报正文等文档抽出的管线机制与技术类型、临床结果、催化事件（变更 D）。

1. **片段校验**：每个条目带 1–4 段原文片段（周数、剂量来自表头或小标题时，须连同那一行一起引用）。规范化后（Unicode NFKC、弯引号转直引号、各类连字符与破折号转 `-`、空白折叠、不区分大小写），每段都必须是存档文本的子串，且不少于 20 个字符。
2. **数字校验**：取值中出现的每个数字（去千分位、去小数末尾的 0）都必须出现在片段里。资产名与试验编号不参与这项校验；取值中资产代号所含的数字（如 VK2735 的 2735）也不参与。
3. **交叉核验**：Qwen 收到与 DeepSeek 相同的文本段和指令，独立抽取，看不到 DeepSeek 的结果。两边条目按类型与关键字段配对；关键字段措辞不同时，按同一资产且片段位置重叠配对。一致的条件按字段逐一判断：两边都为空；或两边都有值、数字集合相同，并且文本相同或两边片段在原文中的位置重叠。任一字段不满足即为分歧。
4. **人工复核**：一致的条目预填「接受」，分歧与单模型条目留空。复核文件签字后，只有「接受」的条目入库；构建时重新做第 1、2 条校验，并核对存档文本哈希，任何不符都使构建失败。
5. **映射**：资产名与本公司推导管线按字母数字规范化后匹配（先完全相同，否则唯一包含）；临床结果须带快照中已有的 NCT 编号。匹配不上的条目不入库，记缺口 `extraction_unmatched`。复核时可以把原文中的试验名改填为 NCT 编号。
6. **时间表述换算为催化窗口**（只含一个年份时才换算）：
   - `Q1 2027`、`1Q 2027`、`first quarter of 2027` → 该季度首日至末日；
   - `H2 2027`、`2H 2027`、`second half of 2027` → 07-01 至 12-31（上半年为 01-01 至 06-30）；
   - `mid-2027` → 06-01 至 08-31；
   - `end of 2026`、`year-end 2026` → 10-01 至 12-31；
   - 只写年份（`2027`、`in 2027`）→ 全年；
   - 时间表述不含年份的催化事件（如 `upcoming`）在抽取时即拒收；
   - 其他写法（`early 2027`、跨年）不换算，窗口留空，原文表述保留在事件描述中，并记缺口 `timing_not_parsed`。
7. **相对标准治疗的优势**：只在原文直接与标准治疗或已上市疗法比较时抽取，写为推断并带置信度。
