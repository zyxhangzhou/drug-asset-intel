# Proposal

对应计划变更 B（基础材料导入与 Stage 0 排除），见 `mydoc/plans/drug-asset-intel/`。

## Why

后续的评分、匹配、应用和 Excel 导出都建立在两份对方材料之上：10 家买方的偏好，以及 149 家标的的指数清单。这两份材料要先完整入库，保留对方的来源 ID 和事实 / 推断口径；并做完第一轮规则排除，才能确定 C 需要拉数据的候选池。

## What Changes

- 导入《10家大型药企创新药资产偏好分析》全部 6 张表。
  - 执行摘要、治疗领域分析、技术类型分析逐格生成声明，事实 / 推断按对方「方法口径」表划分。单元格列出多个来源 ID 的，每个 ID 一条声明。
  - 来源登记的 43 条原样登记，保留来源 ID。
  - 买方概览表没有来源 ID 列，以整个工作簿作为来源，原表的「数据来源」文字记入声明备注。标有「待核实」的单元格不入库，记入缺口清单。
  - 方法口径作为文档留存。
- 导入 149 家指数清单，用 SEC `company_tickers.json` 建立 ticker → CIK 映射；映射不到的进缺口清单。
- Stage 0 排除：由 AI 起草排除名单（类别、理由、一手来源 URL），人工逐家核实；只有核实过的条目入库。
- 来源链接可达性检查：失效链接只标出、不替换，本地路径单独标为本地文件。
- 增加快照构建命令：抓取（联网、写缓存）与构建（只读缓存和材料、重建快照）分开。
- 数据模型扩展：
  - 新增买方财务、买方产品专利到期两张表；
  - 偏好表改为按列存储；
  - 来源表增加原始日期文本和链接状态；
  - 新增排除类别与链接状态两个受控取值集合。

## Capabilities

### New Capabilities

- `buyer-profiles`：对方买方材料的导入与口径映射。
- `target-universe`：指数成分、CIK 映射与 Stage 0 排除。
- `snapshot-build`：从缓存与材料确定性重建快照，输出缺口清单。

### Modified Capabilities

- `intel-data-model`：
  - 实体增加买方财务与产品专利到期；
  - 来源增加原始日期文本与链接状态；
  - 新增受控取值集合。

## Impact

- 新增：`src/intel/ingest/`、`data/manual/`（人工核实的排除名单）、`data/raw/sec/`、`data/raw/links/`。
- 依赖：新增 openpyxl；httpx 从开发依赖移到运行依赖。
- 前端首页的实体计数标签需要同步更新。
- SEC 接口需要在 `.env` 中设置 `SEC_USER_AGENT`（联系人信息）。

**数据核对结果（已在材料中确认）**：

- 43 个来源 ID 全部被引用，所有被引用的 ID 都已登记；
- 149 家清单没有空行，也没有重复。

**Out of scope**：评分与候选名单（E）、CT.gov / XBRL / openFDA 数据（C）、替换失效链接。
