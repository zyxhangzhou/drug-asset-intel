# Design

## Context

- 快照 `data/processed/intel.db` 有 133 家公司的主推荐方向（45 家已复核、0 家深度研究、30 家入选），声明约 6.9 万条：官方接口事实约 3.7 万（CT.gov 试验与结果、SEC XBRL、Nasdaq 行情、openFDA），人工约 6200（复核文件与对方材料），LLM 338。
- 原始响应缓存在 `data/raw/`（`ctgov/<TICKER>.json`、`sec/`、`nasdaq/`、`openfda/`），构建离线读取。
- 复核文件 `data/manual/reviews/<TICKER>.toml` 已支持 `status = "deep"`，但没有收购成本字段；`financial_snapshot.acquisition_cost_low/high` 列存在但从未写入。
- `openpyxl` 已是依赖。快照中「两句话论点」出现在 `scoring/screen.py` 的缺口原因与声明说明里。

## Goals / Non-Goals

**Goals:**

- 一条命令导出覆盖第二部分 1–7 项的 Excel，每个关键值能查到来源。
- 5 家深度研究公司有带来源的收购成本估算。
- 三层抽样的错误率可复现、可查证。

**Non-Goals:**

- 其他公司的收购成本、深度研究范围扩大。
- Excel 样式模板化或可配置列。

## Decisions

### 1. 收购成本 = EV + 市值 × 收购溢价区间，写在复核文件

收购溢价针对股价，所以买方付出的股权对价是市值 ×（1 + 溢价），再加净债务即企业价值口径：EV + 市值 × 溢价。复核文件新增 `[acquisition_cost]`：`low`、`high`（美元）、`method`、`confidence`、`sources`。构建把值写入财务快照的收购成本字段，声明为人工推断。

溢价区间：没有找到给出样本与口径的公开研究（行业网站的数字无一手数据，学术期刊需登录）。改为自建样本：2025-01 至 2026-10 宣布、大型药企现金收购美国上市生物科技公司的 31 宗交易，只记录买方或标的 SEC 文件原文所载的溢价（不自行计算），存 `data/manual/takeover_premiums.csv`；按宣布前一交易日收盘价计算的 18 宗取第 25–75 百分位（39.25%–85.75%，中位数 54%），每宗登记为 `MAN-PREM-<TICKER>` 来源。EV 与市值引用快照行情与 XBRL 来源。备选是在构建里按公式自动算全部公司：会把一个研究的区间套到所有公司，掩盖个案差异（如已有授权、可转债），不采用。

### 2. Excel 每张表一个关注点，关键字段带「来源」列

工作表：说明、候选公司、管线、临床数据、催化事件、来源、缺口。关键字段后紧跟一列「<字段>来源」，内容为「来源 ID（事实 / 推断·置信度）」，多个以分号分隔；来源表含全部被引用来源。备选是每格加批注：不便筛选与核对，不采用。表头冻结、自动筛选、列宽固定；文件写到 `deliverables/候选生物制药公司列表.xlsx` 并提交。导出时间写在说明表，单元格内容只依赖快照，保证同一快照导出内容相同。

### 3. 催化事件合并三个出处

公司披露的催化事件表、复核结论的下一事件、CT.gov 预计主要完成日落在快照日起 24 个月内的 2 期及以上试验；每行标出处与事实 / 推断。CT.gov 行只保留归入管线的试验，避免与公司无关的研究者发起试验混入。

### 4. 抽样分层与分配

- 结构化层：官方接口事实，按来源类型等额分配（CT.gov、SEC XBRL、Nasdaq 行情、openFDA），自动比对：用独立于入库代码的读取逻辑，从缓存原始响应按字段取值再比较（数值按单位换算后比较，日期按日期比较）。
- 复核层：复核文件产生的声明（推荐方向各字段、维度分数理由、收购成本），人工核对取值是否被引用来源支持。
- LLM 层：已签字入库的 LLM 声明，核对原文片段在存档文本中、且片段支持取值。
- 默认每层 30、种子 20261101。错误率区间用 Clopper-Pearson 95% 上限（0 错误时约 9.5%）。人工两层由本助手核对，再派一个独立子代理盲核同一批样本，分歧逐条裁定，记录在报告。

### 5. 用户抽查

用同一种子从已签字复核文件中抽 5 份，生成 Markdown 清单（推荐方向、权益、关键临床数据、下一事件，各附来源网址或存档路径）到 `docs/spot-check.md`；用户核对后把结果记入 `docs/ai-log.md`。

## Risks / Trade-offs

- [溢价研究的样本期与行业口径未必匹配当前生物科技] → 置信度定为中或低，方法列写明区间来源与年份；页面与 Excel 都标为推断。
- [5 份签字文件改动后需重新签字] → 改动只加 `status` 与 `[acquisition_cost]`，提交前列出差异请用户确认。
- [人工核对由 AI 完成，可能与生成时同源偏差] → 独立子代理盲核 + 用户抽查 5 份作为第三道。
- [CT.gov 预计完成日常推迟] → 催化事件表标为推断，附登记的日期类型。
